# HealthNet API Endpoints

## Doctor Controller Endpoints
- POST /doctor - Add a new doctor
- GET /doctor/{id} - Get doctor by ID
- GET /doctor/getmine - Get the currently logged-in doctor
- GET /doctor - Get all doctors
- PUT /doctor - Update doctor information
- DELETE /doctor/{id} - Delete a doctor
- GET /doctor/{id}/available_time?date=YYYY-MM-DD - Get available appointment times for a doctor on a specific date

## Patient Controller Endpoints
- GET /patient/{id} - Get patient by ID
- GET /patient/getmine - Get the currently logged-in patient
- GET /patient - Get all patients

- DELETE /patient/{id} - Delete a patient
